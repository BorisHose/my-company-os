Pflicht-Freigabe bei Außenwirkung – pro Skill einstellbar

Ein Skill legt selbst fest, ob er vor Aktionen mit Außenwirkung anhält und auf deine Freigabe wartet. So laufen reine Hintergrundarbeiten ohne Unterbrechung, während z. B. Mailversand oder CRM-Anlagen weiter von dir freigegeben werden. Das Mock-up links ist klickbar, nichts wird gespeichert.

Hinweis: Deine gespeicherten Vorgaben verlangen für CRM-Anlagen und Tickets immer einen Entwurf zur Freigabe. Für Skills, die so etwas tun, wäre „ohne Freigabe“ ein Widerspruch dazu. Bewusst so speichern?

Entscheidung Boris

Was festgelegt ist

  • Option heißt „Pflicht-Freigabe bei Außenwirkung“ (statt „automatische Freigabe“).
  • Sie wird pro Skill eingestellt, damit Hintergrundarbeiten ohne Unterbrechung laufen können.
Vorschlag Claude

Regeln, wie die Einstellungen zusammenwirken

  1. Drei Stufen je Skill: immer anhalten (Standard) · nur bei ausgewählten Aktionen · im Hintergrund ohne Freigabe.
  2. Profile dürfen abweichen: z. B. Bodo-Profil im Hintergrund, sellify-Profil mit Freigabe, solange es dort noch neu ist.
  3. Ablauf schlägt Skill: Eine im Ablauf gezeichnete „Entscheidung (du)“ hält immer an – auch wenn der Skill auf „Hintergrund“ steht.
  4. Strengste Einstellung gewinnt, wenn ein Schritt mehrere Skills nutzt.
  5. Nichts verschwindet: Jede ohne Freigabe ausgeführte Aktion steht im Verlauf des Auftrags, auf Wunsch auch als Info-Nachricht.
  6. Widerspruch zu deinen Vorgaben wird angezeigt: Für CRM-Anlagen und Tickets hast du festgelegt, dass immer ein Entwurf zur Freigabe kommt. Steht ein solcher Skill auf „Hintergrund“, warnt das Cockpit, verhindert es aber nicht.
